# v0.9.3 Mojibake Logo Cleanup

## What Was Broken

The public app and archived version pages still had visible encoding-risk text in places that could render as mojibake depending on browser, hosting, terminal, or editor interpretation. The most visible problem was the basketball logo/header mark, which relied on a raw emoji or numeric emoji entity instead of an encoding-safe app mark.

Known bad examples included corrupted copyright text, corrupted smart quotes around "Name This Action", corrupted quote characters in older quiz text, corrupted separator dots, and basketball logo text that displayed as mojibake instead of a ball mark.

## Where Corruption Appeared

- The live v3 app header logo used an emoji entity that could still render inconsistently.
- The v1.0 and v2.0 archived app pages used a raw basketball emoji in the header logo.
- The v2.0 archived app page contained mojibake quote and separator sequences in visible quiz/edit/dashboard text.
- The v1.0 archived app page contained raw smart quotes and a raw separator dot in generated UI text.
- README copyright text used a raw copyright glyph instead of a safe HTML entity.

## What Was Fixed

- Replaced the live v3 header basketball emoji/entity with an inline SVG basketball mark.
- Replaced the v1.0 and v2.0 raw basketball emoji header marks with inline SVG basketball marks.
- Replaced mojibake quote sequences with plain ASCII quotes or safe HTML entities.
- Replaced mojibake separator dots with plain ASCII hyphens.
- Replaced raw smart quotes in older generated quiz text with plain ASCII quotes.
- Replaced the README copyright glyph with `&copy;`.
- Confirmed the live `index.html` and `v3.0/hoop-iq-trainer-v3.html` files remain aligned.

## Why Emoji and Raw Special Characters Were Replaced or Escaped

Emoji and raw special characters can be vulnerable to double-encoding, incorrect editor interpretation, and inconsistent rendering across older pages. The header logo is now SVG code, so it no longer depends on an emoji glyph. Visible quotes, separators, and copyright text now use plain ASCII or safe HTML entities where practical.

## Verification Steps

- Search user-facing files for the common stray-currency/spacing mojibake marker.
- Search user-facing files for corrupted smart-quote mojibake markers.
- Search user-facing files for the Unicode replacement character.
