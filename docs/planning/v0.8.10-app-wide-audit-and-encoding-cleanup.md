# v0.8.10 App-Wide Audit and Encoding Cleanup

## Purpose

Stabilize the public Hoop IQ Trainer app before new feature work by auditing encoding, app structure, local role selection, sign-in mockups, documentation, and the synced app files.

## Files Reviewed

- `index.html`
- `v3.0/hoop-iq-trainer-v3.html`
- `README.md`
- `CHANGELOG.md`
- `docs/planning/v0.8.7-coach-player-sign-in-planning.md`
- `docs/planning/v0.8.8-coach-player-sign-in-ui-mockups.md`
- `docs/planning/v0.8.9-local-role-selection-prototype.md`

## Issues Found

- Mojibake appeared in the live app HTML, including corrupted copyright symbols, smart quotes, apostrophes, a range dash, separator dots, and the basketball logo glyph.
- The settings App Notes panel was missing closing tags before `</main>`.
- A small Team Feedback list indentation issue made the HTML harder to audit.

## Issues Fixed

- Replaced corrupted copyright display with `&copy; 2026 Anthony Boyd / Worldmedia Publishing &amp; Consulting LLC. All rights reserved.`
- Replaced the JavaScript copyright constant with a stable `\u00a9` escape.
- Replaced corrupted smart quotes and apostrophes with safe ASCII punctuation.
- Replaced the corrupted `1-5` legend range with ASCII `1-5`.
- Replaced corrupted separator dots with safe `&middot;` entities in generated HTML strings or ASCII separators in text-only strings.
- Replaced the corrupted basketball logo glyph with the numeric entity `&#127936;`.
- Added the missing Settings/App Notes closing tags.
- Cleaned Team Feedback list indentation.
- Confirmed `index.html` and `v3.0/hoop-iq-trainer-v3.html` are aligned after fixes.

## Local Role Selection Sanity Check

- `statRole` exists.
- `localRole` defaults to `guest`.
- Coach Mode, Player Mode, Guest Mode, and Reset Role buttons exist.
- `saveLocalRole()` persists the selected local role.
- `resetLocalRole()` restores Guest mode.
- `updateLocalRoleDisplay()` is called by `updateStats()`.
- `resetProgressConfirm()` preserves the selected local role.

## Sign-In Mockup Sanity Check

- The Coach / Player Sign-In Preview button exists on Home.
- The `signInMockups` screen exists.
- Mockup inputs are disabled.
- The screen states that there is no live login, password handling, database, or player data syncing.
- No real authentication logic was added.

## What Was Intentionally Not Changed

- No basketball terms were revised beyond fixing obvious encoding corruption.
- No diagram generation or SVG label placement was changed.
- No quiz logic, scoring, progress storage, localStorage migration, feedback email flow, or navigation behavior was changed.
- No coach/player authentication feature was added.

## Confirmation

This was a stabilization release only. No new product features were added.
