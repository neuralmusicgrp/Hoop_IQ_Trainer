# v0.8.9 Local Role Selection Prototype

## Purpose

This release adds a local Coach / Player / Guest role selection prototype to Hoop IQ Trainer.

The goal is to let one device remember how the current user wants to use the app without adding real authentication yet.

## Release Type

Local Prototype / UI Behavior

## Version

v0.8.9-local-role-selection-prototype

## Files Updated

- index.html
- v3.0/hoop-iq-trainer-v3.html

## What This Adds

- Local Mode stat in the app header
- Coach Mode button in Player / Settings
- Player Mode button in Player / Settings
- Guest Mode button in Player / Settings
- Reset Role button
- Local role saved inside the existing browser progress object
- Settings status text showing the current local role
- Reset Progress keeps the selected local role

## What This Does Not Add

- Real sign-in
- User accounts
- Password handling
- Backend authentication
- Team database
- Player roster syncing
- Coach dashboard permissions

## Product Direction

This release is the bridge between static sign-in mockups and a future authenticated team version.

It lets the app begin behaving differently by user role while keeping the public offline study experience safe and stable.
