# v0.8.8 Coach / Player Sign-In UI Mockups

## Purpose

This release adds non-functional coach and player sign-in preview screens to Hoop IQ Trainer.

The goal is to show the future account direction without adding real authentication, password handling, databases, or player data syncing yet.

## Release Type

UI Mockup / Planning Implementation

## Version

v0.8.8-coach-player-sign-in-ui-mockups

## Files Updated

- index.html
- v3.0/hoop-iq-trainer-v3.html

## What This Adds

- Home screen button for Coach / Player Sign-In Preview
- Non-functional Coach Sign In mockup
- Non-functional Player Sign In mockup
- Join Team Code mockup
- Create Team mockup
- Planning note explaining that the release does not activate live accounts
- Coming Improvements list updated to include coach and player sign-in previews

## What This Does Not Add

- Live sign-in
- Password handling
- Account creation
- Database storage
- Team roster syncing
- Player progress syncing
- Coach dashboard logic
- Player dashboard logic

## Product Direction

This release makes the future team account vision visible inside the app while keeping the current public basketball study tool stable.

The mockups help coaches, parents, players, and testers understand where the app is going next.
