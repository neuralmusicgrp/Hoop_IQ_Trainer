# v0.9.5 Mobile UX Polish and Audit Fixes

## UX Audit Source Summary

This release follows the post-v0.9.4 UX audit of the current Hoop IQ Trainer app. The audit found that the app was useful and stable as an offline trainer, but the Home screen had become too dense and public-facing text exposed too much roadmap language.

The highest-priority polish areas were Home hierarchy, Team Feedback placement, bottom navigation clarity, active navigation state, mobile readability, quiz clarity, accessibility labels, and README status accuracy.

## What Changed

- Simplified the Home learning flow to focus on Study, Quiz, Diagram Study, Daily 10, and Progress Dashboard.
- Moved secondary actions into a Coach & App Tools panel.
- Kept Team Feedback on Home, but placed it after Coach & App Tools and framed it as a review utility rather than part of the main workout flow.
- Renamed the fixed bottom nav item from Edit to Coach.
- Added visible active state and `aria-current="page"` handling for the bottom nav.
- Improved bottom-nav label sizing while keeping six fixed touch targets.
- Added a concise Name This Action helper: "Look at the diagram, then choose the basketball action."
- Softened account/setup language so it reads as app notes rather than unfinished mockup copy.
- Added straightforward `for` attributes to Coach Tools and Player / Settings labels.
- Updated README to reflect the current offline trainer, local coach tools, static diagrams, and planning-only Supabase/auth status.

## What Was Intentionally Not Changed

- No Supabase code was added.
- No authentication, database, backend, schema, SDK, environment variable, or synced-account code was added.
- Basketball term definitions were not changed.
- Core quiz flow, scoring, localStorage keys, import/export behavior, and diagram generation logic were not redesigned.
- Static diagrams were not deeply redesigned.
- Motion animation was not added.

## Mobile, Nav, Home, Feedback, and Accessibility Notes

- Home now separates primary player workouts from secondary coach/app actions.
- The bottom nav keeps Home, Study, Quiz, Diagram, Stats, and Coach visible.
- The active nav state updates when users enter Study, Quiz, Diagram Study, Stats, Coach Tools, and related secondary tool screens.
- Team Feedback still tells users that email opens a draft and the user must press Send.
- Coach Tools and Settings now have clearer label associations for the straightforward fields.
- The global copyright footer remains outside screen sections and above the fixed bottom navigation.

## Backend/Auth/Database Confirmation

This release is UX polish only. It does not add Supabase, authentication, database tables, backend services, API keys, SDK setup, environment variables, rosters, synced progress, or live team accounts.
