# v0.9.4 Visible Global Copyright Footer

## Issue Found

The copyright footer existed in the live app files, but it was nested inside the Settings/App Notes screen. That meant users could see blank space above the fixed bottom navigation on other screens without seeing the copyright text.

## Why It Was Not Visible Globally

The app renders one main screen at a time by showing the active section and hiding the other sections. Because the copyright text lived inside the Settings section, it only appeared when that screen was active. It was not part of the shared layout below the active screen content.

## Fix Summary

- Moved the copyright text outside the screen-only sections.
- Placed the footer globally inside the main app container and above the fixed bottom navigation.
- Increased bottom padding on the app container so content, copyright text, and the fixed nav do not overlap.
- Kept the footer small and subtle.
- Kept the footer text as safe HTML using `&copy;` and `&amp;`.
- Kept `index.html` and `v3.0/hoop-iq-trainer-v3.html` aligned.

## Verification Steps

- Confirm the footer text appears in both live app files.
- Confirm the footer is outside any single screen-only section.
- Confirm the footer appears before the fixed bottom navigation in the document.
- Confirm no mojibake marker strings remain.
- Confirm the live app files match by hash.
- Run `git diff --check`.
