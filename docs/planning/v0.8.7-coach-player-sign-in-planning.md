# v0.8.7 Coach / Player Sign-In Planning Release

## Purpose

This release is a planning-only milestone for adding future coach and player sign-in features to Hoop IQ Trainer.

The goal is not to build authentication yet. The goal is to define the user roles, expected flows, privacy boundaries, data needs, and future development path before writing production sign-in code.

## Release Type

Planning / Architecture / Product Roadmap

## Version

v0.8.7-coach-player-sign-in-planning

## Current App Status Before This Release

Hoop IQ Trainer currently functions as a basketball terminology and learning app focused on helping players, coaches, and students of the game understand basketball actions, concepts, and diagrams.

Completed areas include:

- Basketball terminology learning experience
- Static concept/action diagrams
- Improved diagram spacing and label cleanup
- Social preview metadata
- Feedback/contact pathway planning
- Public-facing app presentation improvements

Known remaining work before full team/account features:

- Improve terminology definitions where needed
- Continue diagram uniqueness cleanup
- Later revisit motion diagrams after static diagrams are fully cleaned up
- Fix multi-image / multi-step action questions
- Improve directional arrows in generated SVG diagrams
- Add structured coach and player account flows

## Future Sign-In Vision

The app should eventually support two primary signed-in roles:

1. Coach
2. Player

Optional future roles may include:

- Parent / Guardian
- Team Admin
- App Owner / Content Admin

## Coach Sign-In Goals

A coach account should eventually allow a coach to:

- Create or manage a team
- Invite players
- Assign basketball terms or study sets
- Track player progress
- View quiz results
- Recommend concepts for the team
- Submit terminology corrections or improvements
- Save favorite drills, terms, diagrams, or actions
- Access coach-only teaching tools

## Player Sign-In Goals

A player account should eventually allow a player to:

- Join a team using a code or invite
- Study assigned basketball concepts
- Complete quizzes
- Track personal progress
- Review missed questions
- Save favorite terms or diagrams
- Build confidence with basketball IQ over time

## Coach Flow Draft

1. Coach opens the app
2. Coach chooses "Coach Sign In"
3. Coach creates an account or signs in
4. Coach creates a team
5. Coach receives a team invite code
6. Coach shares the code with players
7. Coach assigns learning content
8. Coach reviews player progress

## Player Flow Draft

1. Player opens the app
2. Player chooses "Player Sign In"
3. Player creates an account or signs in
4. Player enters team code
5. Player joins assigned team
6. Player studies terms and actions
7. Player completes quizzes
8. Player reviews progress and missed concepts

## Privacy / Safety Notes

Because this app may be used by youth players, future sign-in development should be careful with privacy and account design.

Important considerations:

- Do not collect unnecessary personal data
- Avoid public player profiles
- Keep team membership private
- Consider parent/guardian requirements for younger users
- Avoid messaging features until safety rules are fully defined
- Keep coach visibility limited to their own team
- Protect player progress data

## Authentication Options To Evaluate Later

Possible implementation paths:

- Firebase Auth
- Supabase Auth
- Clerk
- Auth0
- Custom email/password system

Recommended early direction:

Use a managed auth provider rather than building custom authentication from scratch.
